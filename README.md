# 合格手帳

難関高校受験のための、入試カウントダウン・タスク・時間割・学習ログのサイト。
素の HTML/CSS/JS でビルドはない。データはブラウザの localStorage（キー `gokaku:v1`）だけに置く。

## 動かし方

```
python scripts/serve.py 8460
```

http://localhost:8460 を開く。`serve.py` はキャッシュを切って配信するので、JS/CSS を直したら再読み込みだけでよい。
launch.json の名前は `gokaku`。

## 画面

| 画面 | 中身 |
|---|---|
| ホーム | 第一志望のカウントダウン（残り日数・週数・土日と平日の内訳・今のペースで積める時間）、志望校一覧、今日の勉強（目標メーター）、今日やること、今日の時間割、今週の科目バランス |
| 計画 › タスク | 週の7日分のチェックリスト。前の日にやり残したものは「やり残し」に集まり、今日へ移せる |
| 計画 › 時間割 | 週の時間割（30分刻み）。空きマスのクリックで追加、重なりは保存させない。「前の週をコピー」あり。予定は「実績として記録」で学習ログに入る。下に科目ごとの予定と実績 |
| 記録 | タイマーか手入力で記録。期間（7日/30日/90日/全期間）ごとの合計・平均・日数・連続、科目別の時間と割合、日ごと（90日以上は週ごと）の積み上げ棒。表でも見られる |
| 設定 | 志望校、1日の目標時間、受験科目（3教科なら理社を外す）、時間割の表示時間、テーマ、書き出し/読み込み |

画面上部のカウントダウンはどの画面でも出る。対象は「まだ終わっていない第一志望」、なければいちばん近い入試。

## 決めごと

- 科目は 国語・数学・英語・理科・社会・その他 の固定6つ。色は dataviz の検証済みパレット（国数英理社＝slot 1〜5、その他は灰色）。並びを変えると隣り合う色の見分けが崩れるので変えない。
- 「科目の偏り」は受験科目（その他を除く）で、その週の予定があれば予定、なければ実績で判定する。均等割りの半分未満を「少なめ」、1.8倍超を「偏り」とする。
- 削除や上書きは確認ダイアログを出さず、通知の「元に戻す」で戻せるようにした（全消去と読み込みだけは確認を出す）。
- 記録は未来の日付に入れられない。1件は24時間まで。

## データの形（`gokaku:v1`）

```
{ v:1,
  schools:[{id,name,role,kind,date,announce,memo}],
  tasks:[{id,date,text,subject,done}],
  blocks:[{id,date,start,end,subject,note,logId}],   // start/end は 0:00 からの分
  logs:[{id,date,subject,min,memo,at}],
  timer:{subject,date,acc,since}|null,               // since=0 は一時停止中
  settings:{dailyGoal,subjects,hourStart,hourEnd,theme} }
```

読み込み時は `Store.normalize` が形を整え、壊れた行は落とす。

## 罠

- スマホ幅では下のタブバーを `position:fixed` で出している。ヘッダーに `backdrop-filter` があると fixed の基準がヘッダーになり、タブが上に張り付く。スマホ幅ではヘッダーの backdrop-filter を外してある。
- 動作確認は http://127.0.0.1:8460 で行う（localhost とはオリジンが違い、localStorage が分かれる）。終わったら `localStorage.removeItem('gokaku:v1')`。
